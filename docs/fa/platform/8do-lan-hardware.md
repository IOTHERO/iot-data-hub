# DEVICE 8DO نسخهٔ LAN: تغییرات سخت‌افزار برای طراح PCB

> Firmware این نسخه آماده و کامپایل شده است (`HAS_LAN 1`، پایه‌ها در `config.h`). این برگه
> تغییراتی است که روی برد لازم است. برد قدیمی (بدون W5500) با `HAS_LAN 0` همان Firmware را می‌گیرد.

## ۱. چه حذف می‌شود

| قطعه | توضیح |
|---|---|
| دیپ‌سوئیچ آدرس U6 (کلیدهای AD1..AD7) | آدرس Modbus از منوی تنظیمات است؛ کلیدها لازم نیستند |
| مقاومت‌های پایین‌کش 4.7k خطوط AD1..AD7 | با کلیدها حذف می‌شوند |

**کلید کانفیگ (AD8 قبلی) می‌ماند:** GPIO26، COMMON به +3.3V، مقاومت 4.7k پایین‌کش. روشن = HIGH.
می‌تواند یک کلید تکی (slide یا DIP یک‌تایی) باشد.

## ۲. ماژول LAN: W5500

پیشنهاد: ماژول آمادهٔ W5500 (مثل WIZ850io یا ماژول‌های ارزان «W5500 Lite» با RJ45 و ترانسفورماتور داخلی)
روی هدر، یا تراشهٔ W5500 روی خود برد با کریستال 25MHz و جک RJ45 مگنتیک‌دار (مثل HR911105A).

| سیگنال W5500 | GPIO در ESP32 | جهت | نکته |
|---|---|---|---|
| SCLK | **25** | خروجی | |
| MOSI | **33** | خروجی | |
| SCSn (CS) | **32** | خروجی | مقاومت 10k بالاکش به 3.3V (در ریست، تراشه انتخاب نشود) |
| MISO | **35** | ورودی | GPIO35 فقط ورودی است؛ مناسب |
| INTn | **34** | ورودی | **مقاومت 10k بالاکش به 3.3V لازم است** (GPIO34 pull داخلی ندارد) |
| RSTn | وصل نشود (یا 10k بالاکش + 100nF) | | اگر خواستید از ESP کنترل شود: GPIO36/39 نمی‌شود (فقط ورودی)؛ در آن صورت پایهٔ دیگری لازم است و `PIN_ETH_RST` در `config.h` عوض شود |
| 3V3 | 3.3V | | جریان تا حدود ۱۵۰mA؛ رگولاتور 3.3V برد باید جا داشته باشد (ESP32 + W5500 ≈ ۵۰۰mA اوج). خازن 10µF + 100nF کنار ماژول |
| GND | GND | | |

پایه‌های آزاد بعد از این تغییر: **GPIO36 و GPIO39** (فقط ورودی).

### نکته‌های چیدمان
- خطوط SPI کوتاه (زیر ۵ سانتی‌متر)، دور از خطوط کویل رله‌ها و ULN2803.
- RJ45 و ترانسفورماتور در لبهٔ برد، دور از ترمینال‌های ۲۲۰ ولت رله‌ها؛ فاصلهٔ ایمنی (creepage) بین بخش رله و بخش LAN رعایت شود.
- زمین آنالوگ/دیجیتال W5500 طبق datasheet؛ شیلد RJ45 با خازن 1nF/2kV به GND.
- LEDهای لینک/فعالیت روی جک RJ45 (اگر دارد) از خود W5500.

## ۳. بقیه بدون تغییر

| بخش | GPIO |

| رله‌های K1..K8 | 5، 18، 19، 21، 22، 23، 13، 12 |
| LED DATA / RUN | 14 / 27 |
| RS-485 DE+RE / RX / TX | 4 / 16 / 17 |

## ۴. آزمون پس از ساخت (SAT)

1. برد را بدون کابل روشن کنید: سریال باید `W5500 started` بنویسد (اگر `did not start`: سیم‌کشی SPI یا تغذیه).
2. کابل LAN را وصل کنید: `lan: cable connected` و سپس `lan: connected: <IP>`؛ در منو «کابل LAN: وصل».
3. نوع شبکه «خودکار»: کابل را جدا کنید، باید به وای‌فای برود؛ دوباره وصل کنید، به LAN برگردد.
4. سرور ۱ = هاب (پورت 1883) یا سرور اصلی (8883، TLS): ماژول در داشبورد آنلاین شود و فرمان رله کار کند.
5. فرمان `identify` از سرور: هر دو چراغ ۱۰ ثانیه چشمک بزنند.
